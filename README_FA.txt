وب‌اپ LBANK (PWA)

این پوشه برای انتشار روی یک هاست دارای HTTPS آماده شده است.
1) همه محتویات این پوشه را در ریشه یک سایت یا یک پوشه روی هاست آپلود کنید.
2) آدرس HTTPS فایل index.html را با Chrome اندروید باز کنید.
3) از منوی Chrome گزینه Install app یا Add to Home screen را انتخاب کنید.
4) آیکون LBANK روی صفحه گوشی اضافه می‌شود و برنامه در حالت مستقل باز می‌شود.

رمز نمایشی HTML: 753131

نکته: نصب PWA به HTTPS نیاز دارد (به‌جز localhost). فایل HTML و قفل داخل آن رمزنگاری امن نیستند.
